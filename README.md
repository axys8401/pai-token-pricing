## 计费规则：一个公式，管所有模型

PAI Token 服务计费默认按量后付费：先调用，账单按实际用量结算，公式固定为——

**使用费用 = 输入 token 数量 × 输入单价 + 输出 token 数量 × 输出单价**

所有模型都套这一个公式，区别只在单价。有两处会实实在在影响最后扣多少钱。

**上下文缓存折扣。** 请求命中上下文缓存时，输入 token 部分按折扣计费。最容易命中的场景是多轮对话——系统提示词每一轮都原样重发，命中缓存后这部分输入不再按全价算。具体折扣率官方放在计费文档的附录里，如果你的应用提示词又长又固定，开通前值得翻一眼。

👉 [查看官方计费文档中的上下文缓存折扣附录](https://help.aliyun.com/en/pai/product-overview/billing-of-pai-token-service?userCode=5eqf8rny)

**思考模式的输出。** 输出单价这一栏，在思考模式下按「思维链 + 答案」合计计费。也就是说，模型在给你答案之前“想”的那几千个 token，都算输出、都按输出单价收钱。这笔账后面单独算。

## 区域差价：同一个模型，最多差五成多

区域对价格的影响比很多人想的大。以 Qwen Max 为例，四个部署区域的单价如下（元/百万 tokens）：

| 区域 | qwen3.8-max 输入 / 输出 | qwen3.7-max 输入 / 输出 |
| --- | --- | --- |
| 中国内地（北京） | 14.4 / 43.2 | 14.4 / 43.2 |
| 新加坡 | 17.9856 / 53.958 | 22.4832 / 67.4484 |

| 日本（东京） | 14.4 / 43.2 | 14.4 / 43.2 |

qwen3.8-max 在新加坡比北京贵约四分之一；qwen3.7-max 更明显，新加坡输入单价 22.4832 元，比其余三个区域的 14.4 元高出约五成半，输出单价差距相同。文档里法兰克福和东京区域的 Qwen Max 与 Qwen Plus 标注为 Global 部署范围，价格与北京一致，Qwen Plus 在法兰克福的定价也与北京相同。

选部署区域时这一项值得先看再定。顺带一提，开源模型里有个反例：qwen3-235b-a22b-instruct-2507 在新加坡反而比北京便宜（输入单价 $0.276 对 $0.3444），所以“国际站一定更贵”这个假设并不总成立。

## 三个直接影响账单的细节

**1. 思维链会让输出费用翻好几倍。** 举例：用 qwen3.7-max 做一次推理问答，输入 2,000 token，最终答案 500 token，思维链消耗 2,500 token——输出按 3,000 token 计费，费用为 3,000 × 43.2 ÷ 1,000,000 = 0.1296 元。如果只按看得见的答案长度去估，会以为输出只花 0.0216 元，实际是估算值的 6 倍。开思考模式前先确认任务真需要推理，或者选输出单价更低的型号。

**2. 单次请求超过 256K，输入单价跳到 3 倍。** Qwen Plus 的分档按“单次请求”计算。同样 30 万 token 的内容，一次塞进单个请求（qwen3.7-plus），输入费用是 300,000 × 7.2 ÷ 1,000,000 = 2.16 元；拆成两个 15 万 token 的请求，各按 2.4 元档计，总共 0.72 元。前提是任务不要求模型一次看完全文——全文摘要这类强依赖完整上下文的任务，只能按高档价来。

**3. 新模型不一定更贵。** 直觉上新一代该涨价，实际反过来：同档位下 qwen3.7-plus 输出 9.6 元，qwen3.6-plus 要 14.4 元；256K–1M 长文档档差距更大，前者 28.8 元，后者 57.6 元。选型时按表比价，别按代号新旧猜。

## 这个服务适合谁，不适合谁

PAI Token 服务的定位是 PAI 平台内的模型调用入口：模型评测、模型蒸馏、DSW、FeatureStore、多模态数据处理这些模块都能直接调它。模型清单覆盖 Qwen Max / Plus / VL / Coder、开源的 Qwen3-235B 系列，第三方模型部分文档里列出的是 DeepSeek 系列（v4-pro、v4-flash、r1-0528）。

适合的情况很明确：工作流已经在 PAI 里——数据在 FeatureStore、实验在 DSW 里跑，模型调用留在同一平台，省去导出数据、再对接外部 API 的环节。

两种情况可以绕开。应用强依赖 GPT、Claude、Gemini 这类模型的，这个服务的清单里没有它们；预算需要固定月度金额的团队，按量计费意味着账单随用量浮动，成本没法提前锁死。

## 常见问题

**PAI Token 服务有套餐费或最低消费吗？**
没有。官方计费文档只列了按 token 计费的公式和缓存折扣，没有套餐费或最低消费条目，账单完全随用量走。

**思维链部分单独收费吗？**
收。思考模式下，输出按「思维链 + 答案」合计计费，思维链 token 越多，输出费用越高。Qwen Plus 各档位思考与普通模式的输出单价相同，差别体现在 token 数量上。

**上下文缓存折扣需要申请吗？**
官方规则是命中缓存即享输入折扣，文档里没有额外的申请流程描述。哪些请求会命中、折扣率多少，以计费文档附录的说明为准。

**国际站和国内站的价格一样吗？**
不一样，价格跟部署区域走。以 qwen3.7-max 为例，北京区域输入 14.4 元/百万 tokens，新加坡区域 22.4832 元。开通前先确认账号所在站点，对照对应价格表。
